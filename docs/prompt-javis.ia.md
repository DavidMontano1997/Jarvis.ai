--- CONTEXTO DEL PROYECTO ---

Estoy desarrollando una aplicación para registrar gastos de mi trabajo de mensajería de forma rápida y eficiente.

Actualmente el proceso es manual (Excel) y poco práctico debido a que trabajo en la calle, en condiciones como sol, lluvia y movimiento constante, lo que dificulta interactuar con interfaces complejas.

--- RESTRICCIONES DEL SISTEMA (MUY IMPORTANTES) ---

- La interacción debe ser rápida (menos de 10–15 segundos por registro)
- Debe requerir mínima escritura manual
- Debe funcionar bien en movilidad (uso con una mano)
- Puede haber conectividad inestable
- La entrada de datos puede ser no estructurada (texto libre o imágenes)
- La fricción de uso debe ser mínima

--- SOLUCIÓN PROPUESTA ---

El flujo principal es:
1. Envío un gasto mediante WhatsApp (texto o imagen)
2. Un sistema intermedio procesa ese mensaje usando IA
3. Se extrae la información relevante del gasto
4. Se guarda en una base de datos (Supabase o Firebase)
5. Una aplicación web (React) consume esos datos y los muestra en un dashboard

Tecnologías:
- Frontend: React.js (Vite) + TailwindCSS
- Backend/DB: Supabase o Firebase
- Comunicación: WhatsApp API
- IA: procesamiento de texto e imágenes
